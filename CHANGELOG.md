# 0.1.0 (2026-08-24)

The first release. Heretic replaces
[Momentum](https://github.com/sirsjg/momentum) as the companion to
[Flux](https://github.com/sirsjg/flux).

### Features

- **Runs a team, not a single agent.** A run goes plan → implement → review →
  document → integrate, with each role bound to a model you choose. A reviewer
  that requests changes sends the work back to the implementer with its notes.
- **Reads the real board.** Projects, epics and tasks come from Flux, with
  acceptance criteria and guardrails carried into every prompt, and status
  transitions and summary comments written back.
- **Autonomy stays opt-in.** A task only runs unattended when its epic has
  `auto` on, its epic dependencies are finished, and the task itself is
  unblocked.
- **A worktree per task.** Each run gets its own `git worktree` on its own
  branch, so several can run at once without colliding, and a finished run can
  be merged or discarded from the app.
- **Any agent CLI.** Claude Code, Codex — including `--oss` mode for local
  models — or an arbitrary command with `{{prompt}}` and `{{model}}`
  placeholders.
- **Local and remote models.** Ollama is read through its native API; anything
  OpenAI-shaped (vLLM, LM Studio, llama.cpp, NIM) through `/v1/models`. Hosts on
  other machines are probed concurrently and their models appear alongside the
  local ones.
- **Detection, not configuration.** Agent CLIs and model hosts are scanned for,
  with anything missing explained; anything found becomes a profile in one click.
- **Works behind an identity proxy.** Cloudflare Access service tokens, bearer
  tokens, captured sign-in cookies or arbitrary headers, applied to REST and the
  live event stream alike.
- **Per-run statistics.** Token usage and cost tracked across a run.

### Distribution

- `.dmg`, `.AppImage` and `.deb` bundles for macOS (Apple Silicon and Intel) and
  Linux x86_64, published with a `checksums.txt`. macOS bundles are ad-hoc
  signed; notarisation needs a Developer ID this project does not have.
- A `curl | sh` installer that verifies the checksum before installing, and a
  Homebrew cask for macOS.
